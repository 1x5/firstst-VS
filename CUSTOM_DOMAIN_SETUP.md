# 🌐 Настройка кастомного домена для GitHub Pages

## 📋 Шаг 1: Добавить домен в настройках GitHub Pages

1. Откройте: https://github.com/1x5/firstst-VS/settings/pages
2. В разделе **"Custom domain"** введите ваш домен (например: `example.com` или `www.example.com`)
3. Нажмите **"Save"**
4. GitHub автоматически создаст файл `CNAME` в репозитории

---

## 🔧 Шаг 2: Настроить DNS записи у регистратора домена

Вам нужно настроить DNS записи в панели управления вашего регистратора домена (где вы купили домен).

### Вариант A: Использовать корневой домен (example.com)

Добавьте следующие DNS записи:

**Тип A записи:**
```
Тип: A
Имя: @ (или пустое, или корневой домен)
Значение: 
  185.199.108.153
  185.199.109.153
  185.199.110.153
  185.199.111.153
TTL: 3600 (или Auto)
```

**Или используйте CNAME (если ваш провайдер поддерживает):**
```
Тип: CNAME
Имя: @
Значение: 1x5.github.io
TTL: 3600
```

### Вариант B: Использовать поддомен (www.example.com)

Добавьте CNAME запись:

```
Тип: CNAME
Имя: www
Значение: 1x5.github.io
TTL: 3600
```

---

## ⚙️ Шаг 3: Обновить base path в vite.config.ts

Если вы используете **корневой домен** (example.com), нужно изменить base path:

```typescript
// vite.config.ts
export default defineConfig({
  base: '/', // Вместо '/firstst-VS/'
  // ...
})
```

Если используете **поддомен** (www.example.com), можно оставить как есть или тоже изменить на `/`.

---

## ✅ Шаг 4: Дождаться распространения DNS

После настройки DNS записей:
- Подождите 10-60 минут (может занять до 24 часов)
- GitHub покажет зелёную галочку ✅ когда домен будет настроен
- Проверьте что DNS распространился: https://dnschecker.org

---

## 🔒 Шаг 5: Включить HTTPS (автоматически)

GitHub Pages автоматически:
1. Выпустит SSL сертификат (Let's Encrypt)
2. Включит HTTPS для вашего домена
3. Принудительно перенаправит HTTP на HTTPS

Это может занять несколько минут после настройки DNS.

---

## 📝 Пример настройки DNS для популярных регистраторов

### Namecheap
1. Domain List → Manage → Advanced DNS
2. Add New Record → A Record
3. Host: `@`, Value: `185.199.108.153` (добавьте все 4 IP)
4. Add New Record → CNAME Record (для www)
5. Host: `www`, Value: `1x5.github.io`

### GoDaddy
1. My Products → DNS → Manage DNS
2. Add → A Record: `@` → `185.199.108.153` (и остальные 3)
3. Add → CNAME Record: `www` → `1x5.github.io`

### Cloudflare
1. DNS → Records
2. Add A record: Name: `@`, IPv4: `185.199.108.153` (и остальные 3)
3. Add CNAME record: Name: `www`, Target: `1x5.github.io`
4. **Важно:** Отключите Proxy (серый облачко), оставьте только DNS (DNS only)

---

## 🎯 Рекомендация

**Лучше использовать поддомен www:**
- Проще настроить (только CNAME запись)
- Не нужно менять base path в vite.config.ts
- Работает быстрее

**Схема:**
```
www.example.com → CNAME → 1x5.github.io → GitHub Pages
```

---

## ⚠️ Важно

1. **Не используйте оба варианта одновременно** (корневой и www) без правильной настройки редиректов
2. **Cloudflare:** Отключите Proxy (серый облачко) для DNS записей GitHub Pages
3. **Подождите распространения DNS** — изменения могут занять время
4. **HTTPS включается автоматически** — не нужно ничего делать

---

## 🔍 Проверка

После настройки проверьте:

1. DNS распространился: https://dnschecker.org (введите ваш домен)
2. GitHub показывает зелёную галочку: Settings → Pages → Custom domain
3. Сайт открывается: http://ваш-домен.com
4. HTTPS работает: https://ваш-домен.com (может занять время)

---

**Готово! После настройки DNS ваш сайт будет доступен по вашему домену! 🎉**
