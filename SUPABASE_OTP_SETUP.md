# 🔧 Настройка OTP кодов для восстановления пароля в Supabase

## Проблема: Вместо OTP кода приходит ссылка

По умолчанию Supabase для recovery отправляет ссылку, а не OTP код. Нужно настроить отправку OTP кодов в Supabase Dashboard.

## ✅ Решение:

### 1. Настройка Email Templates для OTP

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **Authentication** → **Email Templates**
4. **Выберите "Magic link"** (это именно то, что нужно!)
5. Настройте шаблон для отправки OTP кодов:

**Важно:** В шаблоне "Magic link" нужно использовать переменную `{{ .Token }}` вместо `{{ .ConfirmationURL }}`

Пример правильного шаблона для OTP:
```
Ваш код для входа: {{ .Token }}

Код действителен в течение 10 минут.
```

### 2. Настройка шаблона "Magic link" для OTP

В шаблоне "Magic link" замените:
- ❌ `{{ .ConfirmationURL }}` (ссылка)
- ✅ `{{ .Token }}` (OTP код)

**Пример шаблона:**

**Subject (тема письма):**
```
Ваш код для восстановления пароля
```

**Body (тело письма):**
```
Здравствуйте!

Ваш код для восстановления пароля: {{ .Token }}

Код действителен в течение 10 минут.

Если вы не запрашивали восстановление пароля, проигнорируйте это письмо.
```

### 3. Проверка настроек Auth

#### Шаг 1: Проверка Email Provider

1. Перейдите в **Authentication** → **Providers**
2. Найдите **"Email"** в списке провайдеров
3. Убедитесь, что Email провайдер **включен** (toggle должен быть активен)
4. Нажмите на **"Email"** для открытия настроек
5. Проверьте следующие настройки:
   - ✅ **"Enable email confirmations"** - должно быть включено
   - ✅ **"Enable email change confirmations"** - должно быть включено (опционально)

#### Шаг 2: Проверка URL Configuration

1. Перейдите в **Authentication** → **URL Configuration**
2. Убедитесь, что **Site URL** установлен:
   ```
   https://uchet1.ru
   ```
3. В **Redirect URLs** должны быть добавлены:
   ```
   https://uchet1.ru/auth/reset-password
   https://uchet1.ru/auth/callback
   ```

#### Шаг 3: Проверка Email Templates

1. Перейдите в **Authentication** → **Email Templates**
2. Убедитесь, что шаблон **"Magic link"** активен
3. Проверьте, что в шаблоне используется `{{ .Token }}` (не `{{ .ConfirmationURL }}`)

#### Шаг 4: Проверка Auth Settings

1. Перейдите в **Project Settings** → **Auth**
2. Найдите раздел **"Email Auth"**
3. Убедитесь, что включены следующие опции:
   - ✅ **"Enable email confirmations"**
   - ✅ **"Enable email change confirmations"** (опционально)
4. Проверьте настройку **"Email template"** - должно быть выбрано **"Magic link"** или **"OTP"**

### 4. Тестирование

После настройки:
1. Нажмите "Отправить код" в настройках
2. Проверьте почту - должен прийти 6-значный код
3. Если приходит ссылка - проверьте настройки Email Templates

## ⚠️ Важно:

- OTP коды действительны ограниченное время (обычно 5-10 минут)
- Каждый код можно использовать только один раз
- Если код не приходит, проверьте папку "Спам"
