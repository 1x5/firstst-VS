# ✅ Чеклист тестирования перед продакшном

## 🎯 Цель
Убедиться что приложение работает корректно перед деплоем в продакшн.

---

## 📋 Чеклист функциональности

### 🔐 Авторизация
- [ ] **Регистрация нового пользователя**
  - Ввести email и пароль
  - Проверить что создаётся аккаунт
  - Проверить что происходит авторизация

- [ ] **Вход существующего пользователя**
  - Войти с правильными данными
  - Проверить что вход работает
  - Проверить что данные загружаются

- [ ] **Восстановление пароля**
  - Нажать "Забыли пароль?"
  - Ввести email
  - Проверить что письмо отправляется (если настроено)

- [ ] **Выход**
  - Нажать кнопку выхода
  - Проверить что происходит разлогин
  - Проверить что данные очищаются

---

### 💰 Доходы

- [ ] **Добавление дохода**
  - Открыть страницу "Доходы"
  - Нажать "Добавить"
  - Ввести: сумму, описание, категорию, дату
  - Нажать "Сохранить"
  - Проверить что доход появился в списке
  - Проверить что баланс обновился

- [ ] **Редактирование дохода**
  - Нажать на существующий доход
  - Изменить сумму/описание/категорию/дату
  - Нажать "Сохранить"
  - Проверить что изменения сохранились

- [ ] **Удаление дохода**
  - Нажать на доход для редактирования
  - Нажать кнопку "Удалить"
  - Подтвердить удаление
  - Проверить что доход удалён из списка
  - Проверить что баланс обновился

- [ ] **Фильтры доходов**
  - Фильтр по периоду: "Неделя", "Этот месяц", "Прошлый месяц"
  - Фильтр по категории
  - Комбинация фильтров
  - Проверить что список корректно фильтруется

- [ ] **Диаграмма доходов**
  - Нажать иконку диаграммы
  - Проверить что диаграмма отображается
  - Проверить что данные корректны

## 🐛 Проверка ошибок

### Консоль браузера (F12 → Console)
- [ ] Нет ошибок JavaScript
- [ ] Нет предупреждений (warnings)
- [ ] Нет ошибок сети (Network tab)

### Сеть (F12 → Network)
- [ ] Все запросы к Supabase успешны (статус 200/201)
- [ ] Нет запросов с ошибками (4xx, 5xx)
- [ ] Нет лишних запросов

## 📝 Как запустить тесты

### Локальное тестирование:
```bash
# 1. Убедитесь что сервер запущен
pnpm dev

# 2. Откройте браузер
# http://localhost:3000

# 3. Откройте DevTools (F12)
# 4. Пройдите по чеклисту выше
```

### Production build тестирование:
```bash
# 1. Соберите продакшн версию
pnpm build

# 2. Запустите preview
pnpm preview

# 3. Тестируйте на http://localhost:4173
```
