## 📋 Инструкция по применению:

### Шаг 1: Создать таблицу в Supabase

1. Откройте [Supabase Dashboard](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в **SQL Editor**
4. Откройте файл `supabase/add_activity_logs.sql`
5. Скопируйте весь SQL скрипт
6. Вставьте в SQL Editor
7. Нажмите **Run** (или F5)

### Шаг 2: Проверка

После выполнения скрипта проверьте:

1. Перейдите в **Table Editor**
2. Должна появиться таблица `activity_logs`
3. Проверьте, что RLS включен (в разделе **Authentication** → **Policies**)

## 🔄 Как это работает:

### Автоматическое сохранение:
- При добавлении транзакции → лог сохраняется в Supabase
- При изменении транзакции → лог сохраняется в Supabase
- При удалении транзакции → лог сохраняется в Supabase

### Автоматическая загрузка:
- При входе пользователя → логи загружаются из Supabase
- Логи синхронизируются между устройствами

### Fallback:
- Если таблица не существует → логи сохраняются только локально
- Если Supabase недоступен → логи сохраняются локально
- Локальные логи всегда доступны через `safeStorage`

## 📊 Структура таблицы:

```sql
activity_logs:
  - id (UUID) - уникальный ID
  - user_id (UUID) - ID пользователя
  - type ('income' | 'expense') - тип транзакции
  - action ('added' | 'updated' | 'deleted') - действие
  - amount (DECIMAL) - сумма
  - description (TEXT) - описание
  - category_name (TEXT) - название категории
  - transaction_id (TEXT) - ID транзакции
  - created_at (TIMESTAMPTZ) - время создания
```
