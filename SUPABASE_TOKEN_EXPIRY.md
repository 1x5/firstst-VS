# ⏰ Настройка времени жизни токенов в Supabase

## Проблема: Токены сброса пароля истекают слишком быстро

Если ссылки для сброса пароля истекают (`otp_expired`), нужно проверить настройки в Supabase Dashboard.

## ✅ Решение:

### 1. Проверьте настройки времени жизни токенов

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **Project Settings** → **Auth**
4. Найдите раздел **"Email Auth"** или **"Password Reset"**
5. Проверьте настройку **"Link expiry time"** или **"OTP expiry time"**

### 2. Рекомендуемые настройки:

- **Минимум:** 1 час (3600 секунд)
- **Рекомендуется:** 24 часа (86400 секунд)
- **Максимум:** 7 дней (604800 секунд)

### 3. Проверьте Email Templates

1. Перейдите в **Authentication** → **Email Templates**
2. Выберите шаблон **"Reset Password"**
3. Убедитесь, что шаблон содержит:
   ```
   {{ .ConfirmationURL }}
   ```

### 4. Проверьте Redirect URLs

Убедитесь, что в **Authentication** → **URL Configuration** → **Redirect URLs** добавлены:
```
https://uchet1.ru/auth/reset-password
https://uchet1.ru/auth/callback
```

## 🔍 Диагностика:

Если токены продолжают истекать:

1. Проверьте, не используете ли вы ссылку повторно (каждая ссылка одноразовая)
2. Проверьте время между запросом письма и переходом по ссылке
3. Проверьте логи в Supabase: **Logs** → **Auth Logs**

## ⚠️ Важно:

- Каждая ссылка для сброса пароля может быть использована **только один раз**
- После использования ссылки она становится недействительной
- Если ссылка истекла, нужно запросить новую
