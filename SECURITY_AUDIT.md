## ⚠️ Важные замечания:

### 1. VITE_* переменные видны в браузере
**Важно понимать:** Переменные с префиксом `VITE_` попадают в клиентский код и видны в браузере.

**Для Supabase это нормально:**
- `VITE_SUPABASE_ANON_KEY` — это публичный ключ, предназначенный для клиента
- Он защищён через RLS (Row Level Security) политики в Supabase
- Это стандартная практика для Supabase

**✅ Всё правильно настроено!**

### 2. RLS политики
Убедитесь что в Supabase включены RLS политики для всех таблиц:
