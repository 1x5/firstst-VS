## 📋 Flow сброса пароля

1. **Запрос письма:**
   - Пользователь вводит email
   - Вызывается `resetPassword(email)`
   - Supabase отправляет письмо с ссылкой на `https://uchet1.ru/auth/reset-password#access_token=...&type=recovery`

2. **Переход по ссылке:**
   - Если hash в URL → обрабатываем сразу
   - Если hash потерялся (404) → читаем из `sessionStorage._reset_password_hash`

3. **Установка сессии:**
   - Парсим `access_token` и `refresh_token`
   - Вызываем `supabase.auth.setSession({ access_token, refresh_token })`
   - Переключаем `mode` на `'reset'`
   - Очищаем hash из URL

4. **Обновление пароля:**
   - Пользователь вводит новый пароль
   - Вызывается `updatePassword(newPassword)`
   - Используется `supabase.auth.updateUser({ password })`
   - Показывается экран успеха

5. **Вход с новым паролем:**
   - Выходим из recovery сессии
   - Переходим на страницу входа

## 📋 Flow смены пароля (из настроек)

Аналогично сбросу, но инициация происходит из настроек пользователя.

## ⚙️ Настройки Supabase

См. `SUPABASE_SETUP_CHECKLIST.md` для полного списка настроек.

**Ключевые URL:**
- Reset Password: `https://uchet1.ru/auth/reset-password`
- Email Callback: `https://uchet1.ru/auth/callback`
