# 🌐 Настройка домена через NS серверы

## 📋 Если у вас есть возможность указать NS серверы

Это значит, что вы можете переключить управление DNS на другого провайдера (например, Cloudflare).

---

## 🎯 Рекомендация: Использовать Cloudflare (бесплатно)

Cloudflare — это бесплатный DNS-провайдер с CDN, что ускоряет загрузку сайта.

### Шаг 1: Зарегистрироваться в Cloudflare

1. Зайдите на https://cloudflare.com
2. Создайте бесплатный аккаунт
3. Добавьте ваш сайт (Add a Site)
4. Введите ваш домен

### Шаг 2: Выбрать план

Выберите **Free** план (бесплатный).

### Шаг 3: Cloudflare покажет NS серверы

Cloudflare даст вам 2 NS сервера, например:
```
ben.ns.cloudflare.com
sue.ns.cloudflare.com
```

### Шаг 4: Указать NS серверы у регистратора домена

В панели управления вашего регистратора домена:

1. Найдите раздел **"DNS"** или **"Nameservers"**
2. Измените NS серверы на те, что дал Cloudflare
3. Сохраните изменения

**Важно:** Замените ВСЕ существующие NS серверы на новые от Cloudflare.

### Шаг 5: Настроить DNS записи в Cloudflare

После того как Cloudflare подтвердит, что домен подключен:

1. Зайдите в Cloudflare Dashboard
2. Выберите ваш домен
3. Перейдите в **DNS** → **Records**
4. Удалите все существующие записи (или оставьте, если нужно)
5. Добавьте новые записи для GitHub Pages:

**Если используете корневой домен (example.com):**
```
Тип: A
Имя: @
IPv4: 185.199.108.153
Proxy: выключен (DNS only - серое облачко)

Тип: A
Имя: @
IPv4: 185.199.109.153
Proxy: выключен

Тип: A
Имя: @
IPv4: 185.199.110.153
Proxy: выключен

Тип: A
Имя: @
IPv4: 185.199.111.153
Proxy: выключен
```

**Если используете www (www.example.com):**
```
Тип: CNAME
Имя: www
Target: 1x5.github.io
Proxy: выключен (DNS only - серое облачко)
```

**⚠️ ВАЖНО:** Proxy должен быть выключен (серое облачко, не оранжевое) для GitHub Pages!

### Шаг 6: Добавить домен в GitHub Pages

1. Откройте: https://github.com/1x5/firstst-VS/settings/pages
2. В разделе **"Custom domain"** введите ваш домен
3. Нажмите **"Save"**

### Шаг 7: Обновить base path (если используете корневой домен)

Если используете корневой домен (example.com), нужно изменить `vite.config.ts`:

```typescript
base: '/', // Вместо '/firstst-VS/'
```

---

## ⏱️ Время настройки

- **Смена NS серверов:** 2-48 часов (обычно 1-2 часа)
- **Распространение DNS:** 10-60 минут
- **SSL сертификат GitHub:** автоматически, 5-10 минут

- ✅ Бесплатно

- ✅ Простая настройка DNS

---

## 🔍 Проверка

1. **Проверка NS серверов:** https://dnschecker.org (выберите NS запись)
2. **Проверка DNS:** https://dnschecker.org (проверьте A или CNAME записи)
3. **GitHub Pages:** Settings → Pages → Custom domain (должна быть зелёная галочка ✅)

---

## 📝 Альтернатива: Использовать DNS регистратора

Если не хотите использовать Cloudflare, можете настроить DNS записи прямо у регистратора домена (без смены NS серверов).

**Инструкция:** Смотрите файл `CUSTOM_DOMAIN_SETUP.md`

---

**Готово! После настройки ваш сайт будет работать на вашем домене! 🎉**
